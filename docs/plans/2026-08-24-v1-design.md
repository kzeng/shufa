# 书法学习 APP - V1 设计文档

## 项目概述

面向 Android 手机和平板的书法学习应用。V1 提供「选贴」与「看贴」两大核心功能，以「不厌书法」APP 为对标参考。

## 技术选型

| 项目 | 选择 |
|------|------|
| 语言 | Kotlin |
| UI | Jetpack Compose + Material 3 |
| 架构 | MVVM（ViewModel + StateFlow） |
| 导航 | Compose Navigation |
| 构建 | Gradle Kotlin DSL |
| 最低 SDK | API 24 (Android 7.0) |
| 目标 SDK | API 35 (Android 15) |
| 包名 | com.example.shufa |
| 模块 | 单 app 模块 |

## V1 功能范围

### 选贴

- 展示可用字帖列表（网格或列表布局）
- 支持按书体（楷书、行书、草书、隶书、篆书）筛选
- 点击字帖卡片进入看贴

### 看贴

- 展示字帖详情（标题、书体、朝代、作者）
- 展示字帖图片内容
- 支持缩放查看细节
- 返回选贴列表

## 数据模型

```kotlin
data class CalligraphyPost(
    val id: String,
    val title: String,
    val author: String,
    val dynasty: String,
    val style: CalligraphyStyle,
    val imageUrl: String
)

enum class CalligraphyStyle {
    KAISHU,    // 楷书
    XINGSHU,   // 行书
    CAOSHU,    // 草书
    LISHU,     // 隶书
    ZHUANSHU   // 篆书
}
```

## V1 数据策略

字帖数据 V1 阶段使用本地 JSON 文件（assets 目录），后续版本可切换为网络 API。
