## 二、商店资料

### 简短描述

精选碑帖，按书体分类浏览与学习书法。

### 完整描述

书法学习是一款面向书法爱好者的碑帖浏览与学习工具。

主要功能：

- 按楷书、行书、草书、隶书、篆书等书体浏览碑帖；
- 查看碑帖作者、朝代、书体、简介和字帖图片；
- 放大、缩小和分页查看字帖内容；
- 收藏喜欢的字帖，方便再次查看；
- 支持本地保存显示主题、字体大小和用户添加的字帖；
- 支持通过关键词搜索更多字帖内容。

本应用不要求注册账号，不提供社交、支付、订阅或广告功能。

部分字帖文字、说明和图片来自第三方网站。使用搜索功能时，搜索关键词会发送至相关第三方网站以获取搜索结果。请勿在搜索框中输入姓名、联系方式或其他不必要的个人信息。

## 七、Data Safety 草稿

### 已从代码确认的行为

- 没有账号注册和登录；
- 没有 Firebase、AdMob、Crashlytics、Google Sign-In 或支付 SDK；
- 没有位置、通讯录、相机、麦克风、短信或电话权限；
- 收藏、主题、字体大小和用户添加的字帖主要保存在设备本地；
- 搜索关键词会发送到 `https://www.zitiewang.com/search.php`；
- 字帖图片从字帖数据记录的第三方网站加载；
- `yac8.com` 的部分图片仍通过 HTTP 明文请求加载；
- 应用使用 Coil、AndroidX、Compose、Room 等开源库。

### 不要直接勾选“没有收集或分享数据”

搜索关键词发送给第三方网站，是否属于 Play Data Safety 中的“应用互动”“搜索历史”或其他数据类别，需要结合 Google 表单定义、第三方网站实际处理方式和隐私政策确认。

建议按以下问题逐项确认：

1. 搜索关键词是否被第三方网站记录、用于分析或与其他数据关联？
2. 第三方网站是否收集 IP 地址、请求时间、设备信息或日志？
3. Coil 和其他依赖是否包含额外的数据收集或诊断功能？
4. HTTP 图片请求是否会传输未加密的网络信息？
5. 用户添加的字帖是否可能包含用户个人信息？

### 可作为填写依据的本地数据说明

| 数据位置 | 处理方式 | 初步判断 |
|---|---|---|
| 收藏、主题、字体大小 | 设备本地 SharedPreferences/Room | 不上传到自有服务器 |
| 用户添加的字帖 | 应用私有文件和 Room | 不上传到自有服务器，需确认内容是否可能含个人信息 |
| 搜索关键词 | 发送到 zitiewang.com | 不能按“完全本地处理”申报 |
| 字帖图片请求 | 访问第三方图片服务器 | 需考虑第三方日志和网络元数据 |

Data Safety 必须与隐私政策、第三方服务实际行为和最终 release 包中的 SDK 保持一致。Google 官方要求所有发布到 Play 的应用完成 Data Safety 表单，即使应用不收集用户数据，也需要提交表单和隐私政策链接。
